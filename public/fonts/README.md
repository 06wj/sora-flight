# Bundled typefaces

Downloaded directly from the official Google Fonts CSS API and fonts.gstatic.com on 2026-09-08. No font service is contacted at runtime.

- **Noto Serif SC**: variable weights 400–700, subset covering all CJK, Kana, and full-width punctuation in src/ui.ts, plus Latin letters and numerals.
- **Zen Kaku Gothic New**: weights 400, 500, 700; Latin, numeric, and UI punctuation subset. Chinese interface text uses the declared local system fallbacks.

These typefaces are distributed under the SIL Open Font License 1.1; their original license notices are included alongside the font files. Official source repositories: https://github.com/google/fonts/tree/main/ofl/notoserifsc and https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew.
