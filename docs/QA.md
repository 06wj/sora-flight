# 验证记录

2026-09-08。以下为本地生产构建的验证记录；GitHub Pages 的发布结果以 [部署工作流](https://github.com/06wj/sora-flight/actions/workflows/pages.yml) 为准。

## 构建与资源

- `npm run build` 通过，包括完整严格 TypeScript 检查。
- `npm test`：**20 / 20 项通过**。17 项模拟测试覆盖操控、暂停、边界、体力、穿环、连击、碰撞无敌、重开、完整航线、自由循环、天气差异、雷区预警与闪避、循环委托和长帧处理；模拟中的自动操控完成 30 环并取得 S 评级。
- 3 项地形测试读取实际 `road.glb` 的二进制 POSITION、索引、访问器偏移 / 步长和节点变换，逐三角形验证路面完全位于运河两岸，中央 `|x| < 11.8` 留空；实际模型 Z 长度为 160 米。在相机 Z 为 0、−159、−160、−3500、−7000 时验证接缝无重叠、无空隙，以及跨网格时保留已铺设路块的世界位置。
- 17 个 GLB 共 **3,697,416 字节**。模型通过 Blender MCP 制作，源文件和美术检查图随项目提供。
- 五种建筑的底部修复检查中，共面问题标记均为 0：移除重叠向下底盖，分离 D / E 的底层玻璃与立柱。场景岸外地面位于 Y=0.12，远景建筑根节点恢复 Y=0，临街建筑保持道路外缘退距；塔楼与远景楼宇采用空间避让。
- 当前游戏主包约 81.06 KB，gzip 约 29.84 KB；Hilo3D 主包约 4.37 MB，gzip 约 1.318 MB。总下载还包括模型、样式与字体。
- 本地 WOFF2 字体约 160 KB，附 SIL Open Font License 1.1 与来源说明，运行时不请求外部字体服务。
